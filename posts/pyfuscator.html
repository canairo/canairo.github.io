Introduction

Hi all. Today I will be talking about a technique for obfuscation of Python scripts by modifying the CPython source responsible for their compilation into Python bytecode (`.pyc` files). This approach is similar to an LLVM pass, where we apply our obfuscation during the compilation steps rather than modifying the Python source code or the bytecode directly.

The goal of this is to brick decompilation and disassembly tools and make `.pyc` files harder to statically reverse engineer. There are a few considerations with this approach, mainly that existing `.pyc` decompilers are not well-equipped to handle obfuscation, and even a simple trick usually suffices to crash them. Additionally, tools like Python's `dis` can crash and fail on malformed opcode / oparg pairs.

As far as I can tell, existing tools typically operate on either the bytecode format directly or obfuscate the source code. Source code obfuscation is, in my opinion, a bit lame, and modifying the bytecode seems like a headache. Applying our obfuscation pass on the C level, where we have access to Python's internal IL and do not need to do things like recomputation of JUMP offsets is a nice thing to have access to. The ultimate goal for our obfuscation is to get our modified compiler to emit blocks of bytecode that could not be produced by ordinary means, because I think this is fun and neat and results in 'cursed' decompiler output.

In terms of actual real-world application, `.pyc` files and bytecode have been known methods of delivery for malware payloads. This is less common than the typical methods of obfuscated Powershell and JavaScript loaders, but it has been known to happen.

This is my first time doing anything of this nature - I have written toy obfuscated programs before but not anything so structured - so forgive me if I use some technical language incorrectly or I get some details wrong.

Getting started: Adding NOPs

We can first add a simple obfuscation pass that adds a chain of 3 do-nothing instructions after each instruction. We operate on the `basicblock` level of our CFG, iterating through each instruction in the block, inserting our junk instructions as required. This is quite simple.

     8   static int
     7   obfuscate(cfg_builder *g)
     6   {
     5   │   for (basicblock *b = g->g_entryblock; b != NULL; b = b->b_next) {
     4   │   │   insert_nops(b);
     3   │   }
     2   │   return SUCCESS;
     1   }
