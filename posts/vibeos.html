introduction

VibeOS is the second-ever entirely hallucinated operating system. It's got cool features like a browser, a networking stack, Tetris, Doom (because infosec people only ever have one joke), and, uhh, some other stuff. I don't really care. I just thought it would be funny to use it as a target for """security research""".

My goal, was, initially, to find a VibeOS fullchain - a browser exploit, then a privilege escalation exploit that would give me a root shell, solely from the VibeOS user visiting a single website. I quickly realised that this is not something you can do, because there is no such thing as 'root' in VibeOS, and the VibeOS browser is written in Python. Bleh!
